# 5 — برنامج الفرع (الكاشير والطابعة)

## ما هذا؟
برنامج نقطة البيع الذي يعمل على جهاز الكاشير **حتى بدون إنترنت**: بيع، مرتجع، وردية، جرد، استلام تحويلات، حضور، وطباعة الفاتورة وملصق الباركود. يحفظ كل شيء في قاعدة محلية (SQLite) ويزامنها مع السحابة تلقائيًا عند عودة الإنترنت.

## أين يُركَّب؟
على **كمبيوتر كل فرع** (ويندوز 10/11 غالبًا) المتصل بطابعة الفواتير وطابعة الملصقات. نسخة لكل فرع، ولكل كاشير جهاز مستقل إن أردت.

## المتطلبات
- Node.js 22.13 أو أحدث ([nodejs.org](https://nodejs.org)).
- `2-api` منشور، وجهاز فرع منشأ من لوحة الإدارة (للحصول على **التوكن**).
- إنترنت مرة واحدة عند التفعيل لتنزيل بيانات الفرع. بعدها يعمل بدونه.

## التركيب
1. انسخ هذا المجلد كاملًا إلى الجهاز (مثلًا `C:\BIGGEST\pos`).
2. انسخ `.env.example` إلى `.env` واملأ:
   ```
   CLOUD_URL=https://erp-api.xxx.workers.dev
   DEVICE_TOKEN=التوكن-من-لوحة-الإدارة
   ```
   (أو اتركهما فارغين وأدخلهما من شاشة التفعيل عند أول تشغيل.)
3. شغّل `start-pos.bat` (لينكس/ماك: `./start-pos.sh`). يفتح المتصفح على `http://127.0.0.1:7070`.
4. سجّل الدخول بحساب كاشير/مدير، وانتظر اكتمال أول مزامنة (تظهر حالة «متصل»).
5. **تشغيل تلقائي مع الجهاز:** شغّل `autostart-windows.bat` مرة واحدة.

> تسجيل الدخول أول مرة يحتاج إنترنت. بعد المزامنة الأولى يعمل الدخول بدون إنترنت.

## إعداد الطابعات
من شاشة **الإعدادات** في البرنامج (للمدير):
- طابعة شبكة: النوع `tcp`، العنوان IP للطابعة، المنفذ `9100`.
- طابعة USB على ويندوز: شاركها باسم (مثل `RECEIPT`) ثم النوع `windows` والاسم نفسه.
- `dryrun`: لا تطبع فعليًا، بل يحفظ ملفًا للفحص (للتجربة).

الفاتورة تُرسل كصورة بصيغة ESC/POS، والملصق بصيغة TSPL، فتعمل مع معظم الطابعات الحرارية.

## البيانات والنسخ
البيانات في `BRANCH_DATA_DIR` (الافتراضي `./data`، والمنفذ `BRANCH_PORT` الافتراضي 7070)؛ مجلد `data/` (تجاهله عند النسخ للأجهزة الأخرى). **لا تنسخ `.env` أو `data` بين فرعين.** النسخ الاحتياطي المركزي يتم من `6-backup-server`.

## الاختبارات
```bash
node --test test/*.test.js
```

## أعطال شائعة
| العرَض | الحل |
|---|---|
| `node` غير معروف | ثبّت Node 22.13+ وأعد تشغيل الجهاز |
| «غير متصل» | افحص الإنترنت وصحة `CLOUD_URL`؛ العمل يستمر محليًا والمزامنة تلحق لاحقًا |
| 401 عند المزامنة | التوكن خاطئ أو الجهاز معطّل؛ أنشئ توكنًا جديدًا |
| الطابعة لا تطبع | جرّب `dryrun` أولًا للتأكد من البرنامج، ثم افحص IP/اسم المشاركة |
| الفاتورة بخط غريب | ثبّت خط IBM Plex Sans Arabic على الجهاز، وإلا يُستخدم Tahoma |

> ملاحظة صريحة: ناقلات الطباعة والبايتات مختبرة بالكود فقط، ولم تُجرَّب على طابعة فعلية. جرّب طباعة فاتورة وملصق قبل الافتتاح.
