# 0002 — كاشير بدون إنترنت: SQLite + outbox + seq

**السياق.** المحل لا يجوز أن يتوقف بيعه بانقطاع الإنترنت.

**الخيارات.** (أ) PWA وIndexedDB. (ب) تطبيق محلي (Branch Agent) بـ SQLite وخادم على localhost. (ج) CRDT.

**المجلس.**
- *المعماري:* (ب) قاعدة حقيقية بمعاملات ومؤشر `seq` بسيط؛ (ج) مبالغ فيه لمجال معاملات يضيف فقط.
- *المشغّل:* يريد طابعة وفتح درج ومسح باركود: يلزم تحكم بالجهاز؛ (ب) أسهل.
- *المتشكك:* ماذا لو تكرر الرفع أو انقطع في المنتصف؟ ← `opId` ثابت + `processed_ops` ⇒ idempotent، وفشل عملية لا يوقف الدفعة.
- *المالية:* SQLite مدمج في Node 22: بلا ترخيص ولا مكتبة.

**القرار.** (ب). الفرع يكتب محليًا فقط ويرفع أحداثًا (لا حالات)، والسيرفر يطبّقها. التنزيل بمؤشر `seq` ولقطة كاملة عند التأخر.

**المقايضة.** عمليات «مرفوضة» ممكنة (مثلًا صنف حُذف)؛ تظهر للمدير بسببها. لا تعارض كتابة على نفس الصف لأن الفرع لا يعدّل بيانات الكتالوج.
