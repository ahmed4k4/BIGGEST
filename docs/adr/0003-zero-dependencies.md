# 0003 — بدون مكتبات خارجية

**السياق.** بيئة البناء بلا شبكة لـ npm، والمستخدم نهائيًا صاحب محل غير تقني.

**المجلس.**
- *المشغّل:* «حمّل وشغّل» بلا `npm install` ولا بناء.
- *المتشكك:* بدون إطار (Next.js/React) سنكتب أدوات واجهة بأنفسنا ← حجمها صغير (`h()` + modal) ومختبرة بالمتصفح.
- *المالية:* لا اعتماديات = لا ثغرات سلسلة توريد ولا صيانة ترقيات.

**القرار.** ES modules عادية، Node ≥ 22.13، والحزمة المشتركة تُنسخ لكل تطبيق (`sync-shared`) لتعمل بمسارات نسبية. Electron وWrangler اختياريان ويُنزَّلان عند الحاجة.

**المقايضة.** لا TypeScript ولا مكوّنات جاهزة. إن كبر الفريق، يمكن ترحيل الواجهات إلى إطار دون لمس الـ API.
