# 0005 — الطباعة بالصورة (Raster)

**السياق.** طابعات الحرارة العربية تختلف في code pages وتشكيل الحروف المتصلة.

**الخيارات.** (أ) نص ESC/POS بجداول الأكواد. (ب) رسم الفاتورة صورة ثم إرسالها نقاطًا.

**المجلس.**
- *المشغّل:* يريد أن تطبع «أي طابعة» بنفس الشكل.
- *المتشكك:* الصورة أبطأ وأكبر ← فاتورة 80مم ≈ 10–20KB، مقبول.
- *المعماري:* نفس مولّد الفاتورة يعطي معاينة الشاشة والطباعة، وQR وCode128 يُرسمان بلا مكتبة.

**القرار.** (ب): Canvas ← 1 بت ← `GS v 0` للفواتير و`BITMAP` لـ TSPL. الناقلات (شبكة/ملف/ويندوز) منفصلة عن المحتوى.

**المقايضة وتحذير.** لم يُجرَّب على أجهزة فعلية؛ الجهد المتوقع عند التركيب: ضبط الكثافة وعرض الورق، واحتمال عكس البت في بعض طابعات TSPL.
