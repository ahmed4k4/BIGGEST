# 0006 — مستويات الإعدادات والتصاريح لمرة واحدة

**السياق.** المطلوب أن يستطيع السوبر أدمن تحديد ما يعدّله الأدمن بحرّية وما يلزمه إذن.

**المجلس.**
- *المشغّل:* لا يريد طلب موافقة لكل شيء، فقط للخطير.
- *المتشكك:* تصريح دائم = ثغرة. ← التصريح مرتبط بإعداد محدد، بمدة، ويُستهلك مرة واحدة (`consume_grant`).
- *المعماري:* المستوى نفسه إعداد يغيّره السوبر أدمن فقط، وكل تغيير بنسخة قابلة للاسترجاع وفي سجل تدقيق غير قابل للتعديل.

**القرار.** ثلاثة مستويات: `free` / `grant` / `super`، وتُفحص داخل الـ API قبل أي كتابة. الأدمن لا يوافق على تصريح نفسه.

**المقايضة.** تعقيد في الواجهة؛ خُففت بصفحة واحدة للتصاريح والمستويات.
