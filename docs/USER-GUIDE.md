# دليل الاستخدام

## الكاشير (تطبيق الفرع)

1. **الدخول:** اسم المستخدم وكلمة السر. يعمل بدون إنترنت. بعد 5 محاولات خاطئة يُقفل لدقيقة.
2. **افتح وردية** من «الوردية والحضور» واكتب النقدي الموجود في الدرج.
3. **البيع:** امسح الباركود (أو اكتب اسم الموديل/اللون/المقاس). الأصناف المتكررة تزيد الكمية. اكتب خصمًا % لو لزم (حدّك المكتوب بجانب الخانة). «دفع» ← نقدي/بطاقة/محفظة (ويمكن الجمع) ← «تأكيد وطباعة». الفاتورة تُحفظ فورًا حتى لو لا إنترنت.
   - تحذير «الرصيد أقل من الكمية»: لو القطعة معك فعلًا أكمل البيع؛ يُسجَّل للمراجعة.
   - **وضع التدريب:** فواتير لا تُسجَّل ولا تؤثر على المخزن.
   - بدون إنترنت: أقصى كمية للصنف الواحد محدودة (إعداد)، وما فوقها يحتاج مديرًا.
4. **المرتجع:** «الفواتير والمرتجع» ← افتح الفاتورة ← «مرتجع» ← الكميات. لا يتجاوز المباع، وخلال المدة المسموحة، والمبلغ يُسترد نقدًا بعد الخصم النسبي.
5. **إعادة الطباعة** محدودة بعدد مرات (الباقي للمدير).
6. **الحضور:** زر واحد (حضور ثم انصراف). اللون: أخضر في الموعد، أصفر ضمن السماحية، أحمر متأخر، أزرق خارج الجدول.
7. **إغلاق الوردية:** عُدّ الدرج واكتب المبلغ **قبل** النظر للمتوقع؛ يظهر العجز/الزيادة.
8. شريط الحالة أعلى الشاشة: «متصل» أو «بدون إنترنت» وعدد العمليات المنتظرة. لا تقلق منها: تُرفع وحدها.

## مدير الفرع (في تطبيق الفرع)

- **استلام التحويلات:** «الجرد والتحويلات» ← اكتب الكمية المستلمة فعلًا. العجز يُسجَّل.
- **الجرد:** امسح كل قطعة؛ العدد يزيد تلقائيًا؛ «اعتماد» يسوّي الفروق في دفتر المخزون.
- **الإعدادات:** الطابعات، المزامنة، وإعادة محاولة العمليات المرفوضة.

## الإدارة (المتصفح)

- **المنتجات:** الموديل ← توليد المتغيرات (ألوان × مقاسات) بالأكواد حسب قالب الأكواد. تعديل قالب الكود يتم من «قالب الأكواد» مع معاينة وفك الكود.
- **المخزن الرئيسي:** إدخال بضاعة، ثم تحويلات للفروع (مسودة ← اعتماد ← في الطريق ← استلام).
- **الفروع والمستخدمون والأجهزة:** إنشاء فرع، مستخدمين بأدوارهم، وأجهزة (التوكن يظهر مرة واحدة).
- **التقارير:** لوحة اليوم، المبيعات، الأكثر مبيعًا، الخزينة، الاستهلاك (حدود الباقة المجانية).
- **الحضور:** جداول الورديات ولوحة النقاط.
- **الطلبات الأونلاين:** متابعة حالتها وتأكيد الدفع والشحن.
- **الصلاحيات (للسوبر أدمن):** مستوى كل إعداد (حر / بتصريح / للسوبر فقط)، منح التصاريح لمرة واحدة بمدة، وسجل التدقيق.

## الأدوار

| الدور | يستطيع |
|---|---|
| سوبر أدمن | كل شيء، ويغيّر مستويات الإعدادات ويمنح التصاريح |
| أدمن | إدارة يومية؛ الإعدادات الحرة فقط، والباقي بتصريح |
| مدير فرع | مرتجعات بعد المدة، خصم أعلى، جرد، استلام تحويلات، إعدادات الطابعة |
| أمين مخزن | المخزن الرئيسي والتحويلات |
| محاسب | التقارير والخزينة |
| كاشير | بيع، مرتجع ضمن الحدود، حضور، بيانات عميل مخفية جزئيًا |

## المتجر الإلكتروني

العميل يتصفح، يختار اللون والمقاس من مسطرة المقاسات، ويطلب بالدفع عند الاستلام. يحصل على رقم طلب يتتبعه بآخر 4 أرقام من هاتفه. الأرقام المتاحة تظهر بشكل «متوفر/آخر قطع/غير متاح».
